# Visual Evidence Methodology

## Source availability

The public repository contains documentation and six SVG interface previews. It does not contain:

- A Canvas App `.msapp` package or unpacked app source.
- Power Fx source files.
- SharePoint schema exports.
- Power Automate flow definitions.
- Production screenshots or screen recordings.
- Production identifiers, tenant information, or personal data.

For that reason, the SVG files are reconstructed previews, not evidence of exact production pixels or live application behavior.

## Reconstruction basis

The preview set is based on the documented application areas and workflow concepts:

- A top-level navigation for Tickets, Dashboard, Archive, Summary, Equipment, and Carriers.
- Equipment and carrier editor layouts.
- Ticket creation and edit controls.
- Dashboard KPIs and status summaries.
- Carrier equipment summary and export actions.
- Change history in the archive view.

Each preview uses a consistent dark dashboard style. Labels, controls, and data relationships are intended to communicate the documented screen concepts while remaining visibly illustrative.

## Privacy treatment

No private information is used in the previews:

- Names, organizations, and locations are generic.
- Device tags, serial-like values, and contact fields are placeholders.
- Dates, quantities, and status examples are not production values.
- Production accounts, links, and tenant details are excluded.

## Fidelity limitations

These previews are not verified against a production app and may differ in typography, spacing, controls, responsive behavior, theme, navigation, data, and configuration. They are suitable for portfolio storytelling, but not for product documentation or user training.

## Replacing previews with real evidence

A future version could use faithful screenshots if a privacy-safe source is supplied, such as sanitized screen captures or an approved, exported demo app. The SVG files should then be replaced or clearly separated from the real evidence with a source and capture date.
